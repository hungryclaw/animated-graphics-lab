# Animated Graphics Lab hackathon demo video project

This folder contains the working material for a short HyperFrames demo video for Animated Graphics Lab.

## Goal

Create a 45-55 second demo video for the HeyGen Hackathon showing AGL as a writer-first tool:

```text
normal article -> automatic visual spot detection -> live HTML/GSAP preview -> HyperFrames render -> GIF/MP4 export
```

Agent integration is a supporting point, not the main path. Do not make the video about `AGL_GRAPHIC` tags in the main cut.

## Core message

AI can write articles fast, but many articles still feel visually flat. AGL finds the places where motion helps, previews animations locally, renders approved visuals with HyperFrames from HeyGen, and exports GIF/MP4 files that work on Medium, Substack, X, newsletters, docs, and owned sites.

## Best line

```text
HTML when you are designing. GIF when you are publishing.
```

## Files

- `voiceover.txt` — final narration text for TTS/recording.
- `storyboard.md` — scene-by-scene visual plan for the HyperFrames composition.
- `asset-checklist.md` — what is already available and what must be gathered manually.
- `source-materials.md` — source claims, repo facts, sample article, and UI text.
- `shot-list.md` — exact screen recordings/screenshots to capture.
- `hyperframes-brief.md` — implementation notes for building the HyperFrames video.

## Suggested render shape

Use 16:9 landscape first for hackathon/demo judging. If time allows, make a 9:16 cut afterwards for X/shorts.

Recommended duration: 50 seconds.
