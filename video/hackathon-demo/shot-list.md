# Shot list

Use these for the screen-recording pass. Keep each shot short. The HyperFrames edit can simulate anything missing, but real product footage will make the demo stronger.

## Shot 1: Bland AI article

Length: 3-4 seconds

Capture:

- A boring article page or markdown editor with long paragraphs.
- Highlight a text-heavy paragraph.

Can be simulated in HyperFrames if needed.

## Shot 2: Platform problem

Length: 5-6 seconds

Capture or simulate:

- Cards labeled Medium, Substack, X, Newsletter, Docs.
- HTML animation card blocked from embedding.
- GIF/MP4 badges passing through.

Probably easiest to simulate in HyperFrames.

## Shot 3: AGL app intro

Length: 5-6 seconds

Capture:

- App open in article mode.
- Paste this article:

```md
# Memory Makes Agents Compound

Most agents are stateless workers. They complete a task, lose the context, and repeat the same mistakes later.

The difference is not magic. It is continuity. A memory-backed agent can use previous results to make the next run better.
```

## Shot 4: Automatic visual spotting

Length: 8-9 seconds

Capture:

- Click the action that analyzes the article / finds visual spots.
- Progress state if it looks good.
- Visual spots appearing.

If the UI still says a slightly different label, keep it. In the final edit, use overlay text:

```text
Article -> visual spots -> live previews
```

## Shot 5: Preview before render

Length: 7-8 seconds

Capture:

- Generate preview for one spot.
- Show preview animation.
- Show revise or approve action.

If revision UI is not ready or too slow, show preview and add HyperFrames overlay: "Preview first. Render after approval."

## Shot 6: HyperFrames render

Length: 7-8 seconds

Capture or simulate:

- Render status in app, if available.
- Terminal render output, if cleaner.
- Output file appearing.

Overlay:

```text
Powered by HyperFrames from HeyGen
MP4 + GIF export
```

## Shot 7: Portable output

Length: 7-8 seconds

Capture or simulate:

- Same GIF/MP4 placed inside article/social mockups.
- Cards labeled Medium, Substack, X, Newsletter, Docs.

This can be fully built in HyperFrames if real platform drafts are annoying.

## Shot 8: Closing card

Length: 5-6 seconds

Capture/simulate:

- Product title.
- Optional local output folder/tree.

Text:

```text
Animated Graphics Lab
Local-first article visuals
Built for the HeyGen Hackathon
Powered by HyperFrames
```

Final spoken line:

```text
Animated Graphics Lab. HTML when you are designing. GIF when you are publishing.
```
